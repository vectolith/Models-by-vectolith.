# Local dataset integrity and protected splitting

Use only local/private datasets and outputs. This utility never uploads data.

- `python scripts/core_prime_local_dataset.py audit corpus.jsonl`: validates JSONL object rows, unique IDs, and duplicate serialized row content (prints counts/errors, not row contents).
- `python scripts/core_prime_local_dataset.py split corpus.jsonl --out-dir /secure/new-directory --key-file /secure/split-key`: deterministic HMAC-based split with a secret key of at least 32 bytes. The output directory must be empty/new; directory and files receive restrictive POSIX permissions where supported.

The split output includes train/dev/holdout JSONL and a local manifest with hashes/counts. Keep the key, holdout, and manifest in controlled storage outside the public repository. The holdout generated by this tool is only as novel as the input corpus; it does not detect external leakage, certify source permissions, or replace secure custody. Do not reuse previously exposed holdout records. Split percentages are configurable. This helper is not a training launcher.
