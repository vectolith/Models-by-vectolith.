- `snapshot_additional_teacher.py` resolves a public Hub model's current revision to a full immutable commit SHA, downloads that exact revision, validates the expected architecture and license identifier, and emits a manifest containing the complete file inventory, byte sizes and SHA-256 hashes. License evidence records any upstream license-file hashes and the exact-revision model-card reference. If a candidate snapshot has no license file, the manifest explicitly records `model_card_tag_only_pending_human_review`; this is not a legal approval or qualification. Every candidate remains pending human legal review, training-output permission is unverified, no teacher is qualified, and this workflow does not start training.
