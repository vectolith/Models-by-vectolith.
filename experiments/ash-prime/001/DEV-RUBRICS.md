# Development Rubrics — ASH PRIME Experiment 001

Version: cp001-dev-rubric-v1. Original development-set scoring only. Each criterion is scored 0–2: 0 = fails or materially incorrect; 1 = partial, incomplete, or minor error; 2 = meets requirements. Scoring requires review of the actual response and task; no grades are assigned here.

- **Instruction following:** constraint compliance, requested format and completeness.
- **Comprehension:** accurate extraction, interpretation and coverage of supplied text.
- **Reasoning:** valid steps, explicit assumptions and conclusion supported.
- **Arithmetic:** correctness, method and units.
- **Structured output:** schema/format validity and semantic correctness.
- **Coding comprehension:** accurate analysis of code behavior and requested explanation.

Score records must include task ID, criterion score, evidence quote/observation, rationale, grader identity and rubric version.
